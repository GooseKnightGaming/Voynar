# The Voynar Folios

A manuscript written in **Voynar**, an invented script of 62 glyphs, inspired by the Voynich Manuscript (Beinecke MS 408).

Every folio carries a real message. How the script works is not published: working that out is the challenge.

**Read the folios:** https://gooseknightgaming.github.io/Voynar/

## What's here

| Path | Contents |
| --- | --- |
| `index.html` | The reading room: every folio, in glyphs or transcription, plus the glyph chart |
| `folios/` | One transcription file per folio, and `manifest.json` listing them |
| `assets/fonts/` | The Voynar fonts used to display the glyphs |

## Transcription

Each glyph is written with one letter or digit (`A`–`Z`, `a`–`z`, `0`–`9`), shown in the glyph chart on the site. The letters are labels only and say nothing about what a glyph means. Lines and spaces are as they appear on the folio.

## Think you've read a folio?

Open an issue with the folio number and the first five words of your reading. Please don't post a full solution publicly.
